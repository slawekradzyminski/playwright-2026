# Bug reports

Write all content in this folder in English. Create one file per bug named
`BUG-NNNN-short-description.md` using [TEMPLATE.md](TEMPLATE.md). Choose the next
available number and keep it after transferring the report to Jira. Check for
an existing report first; add new evidence to that report instead of duplicating it.

In Jira, copy the table values into the corresponding fields of a **Bug** issue
and paste the sections from **Description** onward into its **Description** field.
Adjust priority and component names to match the Jira project's configuration.
After creating the issue, add its link to the report's **Jira** field. A file in
this repository does not create a Jira issue automatically.

Include a minimal reproduction, expected and actual results, and evidence with
the verification date and environment. Distinguish confirmed behavior from
suspected causes and expectations requiring confirmation. Exclude real account
passwords, tokens and personal data. Use test data in examples.
