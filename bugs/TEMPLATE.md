## Description

What fails, and how does it affect users or data?

## Preconditions

Required permissions, data and application state. Use test data or placeholders.

## Steps to reproduce

1. First step.
2. Next step with exact input data.

## Expected result

Correct behavior. Reference the requirement or mark the expectation as requiring confirmation.

## Actual result

Observed behavior, response status and relevant response body fields.

## Evidence

Minimal request and sanitized response, log or attachment path.
State the reproduction frequency if verified. Only report results of attempts
that were actually performed.

## Acceptance criteria

- Specific, verifiable behavior after the fix.
- A relevant regression scenario that must continue to work.
